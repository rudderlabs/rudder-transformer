# Loops RETL Functionality

## Is RETL supported at all?

No. `warehouse` is not in `supportedSourceTypes` in `db-config.json`.

## Which type of RETL support does it have?

None. JSON Mapper, VDM v1 (`supportsVisualMapper`) and VDM v2 (`record` message type) are not applicable, and the workflow has no `mappedToDestination` or `record` handling.

## Connection config

None.
